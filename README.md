# Petal & Verse 🌸

A botanical poetry writing and inspiration studio with Toffee Rose and Cocoa Cosmos themes.

## How to install as a Real PWA App on Android:
1. Host these files on any static host (GitHub Pages, Vercel, Netlify, or local server).
2. Open the URL in Samsung Internet or Google Chrome on your phone.
3. Tap the menu and select **"Add to Home Screen"** or **"Install App"**.
4. It installs as a native standalone app with full offline support and zero browser bars!
